# Third-party components and models

This project is licensed under Apache-2.0 (see [`../LICENSE`](../LICENSE) and
[`../NOTICE`](../NOTICE)). This file collects the licensing of the third-party
components this project depends on, redistributes, or interoperates with. It
does not change this project's own terms.

**No third-party model weights or runtime binaries are stored in this
repository.** They are downloaded on demand by the scripts in `scripts/`, and
each download is verified against a pinned sha256 checksum.

## ONNX Runtime (Microsoft)

- Source: https://github.com/microsoft/onnxruntime
- License: **MIT**
- Use: the inference runtime behind `embed_core` (EmbeddingGemma 2) and
  `ocr_core` (PP-OCRv5). The library is loaded dynamically from an absolute
  path at runtime (`load-dynamic`); it is never linked into the crates and never
  committed here.
- Obtain it with `scripts/fetch_onnxruntime.ps1`; the pinned checksum lives in
  `scripts/checksums/onnxruntime-<platform>.sha256`.

## llama.cpp and prebuilt GGUF runtime packages (ggml-org)

- Source: https://github.com/ggml-org/llama.cpp
- License: **MIT**
- Use: the optional `llama.cpp` embedding backend. The `llama-embed-worker`
  binary links against the llama.cpp import libraries; the runtime DLLs are
  downloaded on demand.
- Obtain it with `scripts/fetch_llama_runtime.ps1`; the pinned checksum lives in
  `scripts/checksums/llama-<version>-<platform>.sha256`.

## EmbeddingGemma 2 (Google)

- Source: https://ai.google.dev/gemma (Hugging Face: `google/embeddinggemma-2-300M`)
- License: **Gemma Terms of Use** (not an OSI-approved licence — review the
  terms before commercial use)
- Use: the embedding model behind `embed_core`. Both the ONNX export and the
  GGUF quantisation are downloaded on demand and verified by sha256; the
  weights are never redistributed here.

## PaddleOCR / PP-OCRv5 (PaddlePaddle)

- Source: https://github.com/PaddlePaddle/PaddleOCR
- License: **Apache-2.0**
- Use: the OCR engine behind `ocr_core`. The PP-OCRv5 mobile ONNX models
  (detection / recognition / direction classification) are downloaded on demand
  and verified by sha256. No PaddlePaddle binary is bundled or redistributed.

## RapidOCR (RapidAI) — reference implementation

- Source: https://github.com/RapidAI/RapidOCR
- License: **Apache-2.0**
- Use: reference implementation only. No RapidOCR code is packaged here; the
  PP-OCRv5 models it republishes are obtained from the upstream PaddleOCR
  repository.

## Rust dependencies

The crate dependencies listed in `Cargo.lock` carry their own licences; the
most relevant ones are MIT (`ort`, `tokenizers`, `image`, `serde`, `serde_json`,
`sha2`, `hex`, `thiserror`) and the Unicode/ICU-style licences of the
`tokenizers` transitive dependencies. Run `cargo license` or inspect
`Cargo.lock` for the authoritative list.

## Evaluation assets

The images under `eval/public/images/` are **CC0 or public domain**; their
per-file source, author and licence are recorded in `eval/public/SOURCES.md`.
The OCR fixtures under `eval/public/ocr/` are generated by
`eval/tools/gen_ocr_fixtures.py` and contain no third-party material.
