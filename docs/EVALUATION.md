# Evaluation

This directory holds the **public** evaluation assets. Nothing here contains
private material: every image is CC0 1.0 or public domain, and the private
evaluation set (and any golden vectors derived from it) is not part of this
repository.

```
eval/
  public/
    images/        36 CC0 / public-domain images
    manifest.jsonl machine-readable source, author, licence and sha256 per file
    SOURCES.md     the same information, human readable (generated)
    ocr/           OCR fixtures (generated by tools/gen_ocr_fixtures.py)
  queries.jsonl    bilingual text queries and their expected hits
  expected.jsonl   per-query expected hits
  similar.jsonl    image-query groups (image → image evaluation)
  suites/          consistency suites (text inputs + image file names)
  baseline/        the committed public baseline report
  tools/           helper scripts
```

## Running the retrieval evaluation

```bash
cargo run --release -p embed_core --example retrieval_eval -- \
  --ort_lib <ONNX_RUNTIME_LIB> \
  --model_dir <EMBEDDINGGEMMA2_MODEL_DIR> \
  --pub_dir eval/public/images \
  --queries eval/queries.jsonl \
  --expected eval/expected.jsonl \
  --sim eval/similar.jsonl \
  --threads 4 --soft_tokens 140 --top_k 10 \
  --history_dir eval/history \
  --snapshot eval/baseline/public-baseline-ort-cpu.json
```

The committed baseline (public set only, ORT-CPU backend) is documented in
[`baseline/README.md`](baseline/README.md).

## Consistency check (required for model / runtime upgrades)

`cargo run -p embed_core --example embed_consistency -- capture|check ...`

`capture` records the vectors of a suite together with the sha256 of every
input; `check` recomputes them and compares against a golden file.

| Scenario | Gate |
|---|---|
| Same backend (ORT-CPU → ORT-CPU) | element-wise equal within `--max_abs 1e-6`, plus a cosine sanity check |
| Cross backend (ORT ↔ llama.cpp) | cosine ≥ **0.99** |
| Input drift (sha256 mismatch) | hard error — re-run `capture` |

Upgrading llama.cpp, the EmbeddingGemma 2 export, the image preprocessing or the
worker protocol **requires** this check to pass. A change to the vector
semantics is a **MAJOR** release, because vectors stored by earlier versions
are not comparable with new ones.

## Keeping the licences honest

`eval/public/manifest.jsonl` is the source of truth. After editing it:

```bash
python eval/tools/gen_sources_md.py
```

The script refuses to generate `SOURCES.md` if any file is not CC0 or public
domain — files whose licence cannot be confirmed must be removed from the
public set entirely.
